Complete Feature List

Every feature, organised by category

A full breakdown of what's included across all SmokingTracker plans.

📱 Client Logging ▾
  • Three-tap session logging — substance, amount, method in under 5 seconds
  • Optional fields — mood rating, craving score, trigger category, location, free-text notes
  • Fast-use warning — in-app alert if session interval is unusually short
  • Works in any mobile browser — no app store download required
  • Session calendar heatmap — client-side view of logged use over time
  • Longitudinal statistics — frequency, consumption, trend charts for the client
  • Time-since-last-session counter — visible on home screen
  • Goal tracking — client sets reduction targets, progress visible in app
🖥️ Practitioner Dashboard ▾
  • Client list with traffic-light status — green/yellow/red risk at a glance
  • Risk score algorithm — uses frequency, trend, craving, fast-use events
  • Client detail view — calendar heatmap, trend charts, mood/craving plots
  • Trigger breakdown — ranked by session count: stress, social, boredom, habit, pain
  • Method & substance analytics — flower, vape, concentrate, edible split
  • Time-of-day and day-of-week patterns — identify use schedule
  • Session notes — free-text annotations attached to any date
  • Event flags — relapse, goal achievement, medication change
  • Custom date range — 4, 8, 12 weeks or custom
  • Real-time data — updates as client logs, no manual sync
📄 Clinical Reports ▾
  • One-click PDF export — generates instantly from dashboard data
  • Includes — session calendar, use trends, mood/craving chart, top triggers, method breakdown, clinical notes
  • Custom date range — weekly, monthly, full programme span
  • Clinician name and client ID — on all exported documents
  • EHR-ready formatting — structured for direct paste or attachment
  • Referral quality — data sourced from timestamped EMA entries with methodology noted
🔒 Privacy & Compliance ▾
  • HIPAA — Business Associate Agreement (BAA) available for all clinical accounts
  • GDPR — Data Processing Agreement (DPA) available, EU data residency option
  • 42 CFR Part 2 — substance use disorder record confidentiality requirements met
  • AES-256 encryption at rest — all client data
  • TLS 1.2+ in transit — all API and web traffic
  • Role-based access — practitioners see only their own clients
  • Full audit log — timestamped access events, tamper-evident
  • Client consent model — client-initiated connection, revocable at any time
  • Right to erasure — full account deletion on request
🤝 Client Management ▾
  • Secure client invite — link-based, no app store, setup in under 2 minutes
  • Multi-client caseload — all clients visible on one dashboard
  • Clinician shown in client app — client can see their connected practitioner
  • Multiple clinicians per organisation — admin access across a team
  • Client self-monitoring — clients see their own data on the tracker side
🏆 Client Engagement ▾
  • Achievement system — milestones for logging consistency, abstinence streaks, goal adherence
  • Progress bars — next milestone always visible
  • Relapse-resilient — achievements not deleted on relapse, removing shame spiral
  • Urge surfing tool — in-app craving management exercise
  • Money saved calculator — real-time estimate based on usage reduction
  • Home screen summary — time since last session, current streak, recent trend
